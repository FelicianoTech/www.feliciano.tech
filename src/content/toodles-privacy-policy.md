October 8, 2025

The app Toodles does not collect any data from the user nor the user's device without concept.
It does not track IP addresses nor location.
It does not contain/show any advertisements.
It does save the account API token (provided by a parent) for a Todoist.
This is what enables the app to work. This token stays on the device.
